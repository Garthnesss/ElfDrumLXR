# ElfDrumLXR (codename: lxr-plugin)

A DAW plugin (VST3/AU + standalone) that runs Erica Synths' open-source LXR-02 firmware sound engine and sequencer natively — the real GPL-3.0 code, compiled for the host — with full hardware `.SND` kit / `.PAT` pattern compatibility.

Status: **plan complete, code not started** (Oct 28, 2026). See STATUS.md.
